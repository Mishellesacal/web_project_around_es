# Tripleten web_project_around_es
Autor: Mishelle Dayan Sacal 
Titulo: Around es
Description: En este proyecto hicimos que cuando un usuario pongan mal la informacion que nosotros queremos recibir, que no le deje mandar el formulario y le aparesca comentarios en rojo para que el identifique que esta mal o que debe de correjir

técnicas utilizadas
HTML5 para la estructura de la página.
CSS3 para los estilos y el diseño adaptable.
JavaScript para la interactividad.
Programación orientada a objetos (POO) mediante clases de ES6.
Validación de formularios con las propiedades de HTML5 y ValidityState.
